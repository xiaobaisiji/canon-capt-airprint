## 10. 附录：路径与命令速查

### 10.1 关键文件

| 路径 | 作用 |
|---|---|
| `/etc/cups/cupsd.conf` | 监听、ACL、`ReadyPaperSizes`、`ServerAlias` |
| `/etc/cups/ppd/LBP7010C.ppd` | 队列 PPD（**不要手工改**） |
| `/etc/cups/ppd/LBP7010C.ppd.bak.*` | PPD 备份 |
| `/etc/systemd/system/cups.socket.d/10-lan-631.conf` | 631 常驻监听 |
| `/etc/systemd/system/ccpd.service` | `Type=forking` |
| `/etc/systemd/system/ccpd.service.d/20-locale.conf` | **locale 修复** |
| `/etc/systemd/system/ccpd.service.d/40-preflight.conf` | 启动前清助手 + USB 复位 |
| `/etc/ccpd.conf` | `队列名 → 设备路径` 映射 |
| `/etc/avahi/services/canon-airprint.service` | AirPrint 广播 |
| `/etc/udev/rules.d/50-canon-lbp-no-autosuspend.rules` | 禁止 USB 自动挂起 |
| `/etc/udev/rules.d/51-canon-lbp-link.rules` | 固定设备名 |
| `/usr/share/cups/usb/capt-printers.usb-quirks` | 阻止 CUPS usb 后端抢占 |
| `/usr/local/sbin/canon-usbreset` | USB 设备复位 |
| `/usr/lib/cups/filter/pstocapt3` | PS → CAPT 过滤器 |
| `/usr/lib/cups/backend/ccp` | CAPT 后端（连 ccpd） |
| `/usr/sbin/ccpd`・`/usr/sbin/ccpdadmin` | CAPT 守护进程 / 配置工具 |
| `/usr/bin/captmoncnacb` | **真正操作 USB 的 32 位助手** |
| `/usr/share/captemon/msgtable*.xml` | 状态消息表（只有 en，locale 必须匹配） |

### 10.2 CAPT 协议速查

```
ccpd 监听：
  59687  数据端口（CUPS backend 连这里，队列 URI 用这个）
  59787  状态/UI 端口（过滤器/状态监视器用）

报文格式：
  请求  "CCP2" + int32(长度) + 队列名
  应答  "CCP3" + int32(返回码)
        1 = TRUE 就绪    0 = FALSE        -1 = PARAMERR
       -2 = NOQUEUE      -3 = BUSY        -4 = NOTHREAD

手工探测（任一 Linux 机器可跑）：
  python3 -c "
import socket,struct
q=b'LBP7010C'
s=socket.create_connection(('127.0.0.1',59687),3)
s.sendall(b'CCP2'+struct.pack('<i',len(q))+q)
print(struct.unpack('<i', s.recv(8)[4:8])[0])"
```

### 10.3 AirPrint 排障速查

```bash
# 客户端能否访问（在客户端上）
#   浏览器打开 http://<NAS-IP>:631/printers/<队列>，应返回 CUPS 页面

# 服务端广播
avahi-browse -rt _ipp._tcp

# iOS 到底有没有发起浏览（在 NAS 上抓包，期间操作手机打印面板）
sudo tcpdump -i any -n -A -c 500 'udp port 5353 or tcp port 631'
#   若看不到 _ipp._tcp 查询 → iOS 在浏览阶段已过滤，回去检查 TXT
#   若有查询无响应 → avahi 接口问题
#   若有响应但无 631 连接 → 仍被 TXT 过滤
```
