## 8. 日常运维

### 8.1 日志位置

| 日志 | 内容 |
|---|---|
| `journalctl -u ccpd` | `bidiNew`、`Printer open() path=... errno=...` |
| `journalctl -u cups` | CUPS 启动错误 |
| `/var/log/cups/error_log` | 作业与过滤器错误（`ccp send_data error` 等） |
| `/var/log/cups/access_log` | 每个客户端请求（排查 403、客户端是否连通） |
| `dmesg | grep -i -E 'captmon|usblp'` | 助手崩溃、USB 重连 |

### 8.2 常用命令

```bash
lpstat -p -d -v                      # 队列与设备 URI
lpstat -o                            # 未完成作业
lpstat -W completed -o               # 历史作业
lpoptions -p LBP7010C -l             # 该队列可选项（纸张/分辨率等）
ipptool -tv ipp://127.0.0.1:631/printers/LBP7010C get-printer-attributes.test
avahi-browse -rt _ipp._tcp           # AirPrint 广播
fuser -v /dev/usb/lbp7010c           # 谁占着设备
```

### 8.3 升级注意事项

- **fnOS / CUPS 升级**可能重写 `/etc/cups/cupsd.conf`、重置 systemd 单元 → 重新跑一遍部署脚本
- 备份目录建议保留：`/etc/ccpd.conf`、`/etc/cups/cupsd.conf`、`/etc/cups/ppd/*.ppd`、`/etc/systemd/system/ccpd.service*`、`/etc/avahi/services/*.service`、`/etc/udev/rules.d/5*-canon*`
- 驱动包体积 122MB，装完可删 `/opt/canon-capt/drv.tar.gz`

### 8.4 安全提示

本教程把 CUPS 的访问控制设为 `Allow all`（家庭/办公内网常见做法），意味着**同网段任何设备都能打印、查看队列**。管理页面（`/admin/conf`、`/admin/log`）仍要求认证。若在内网暴露风险较高的环境，可改为：

```conf
<Location />
  Order allow,deny
  Allow <LAN-SUBNET>
  Allow 127.0.0.1
</Location>
```

## 9. 回滚

```bash
systemctl disable --now ccpd canon-ipp9100 2>/dev/null
lpadmin -x LBP7010C
rm -f /etc/avahi/services/canon-airprint.service
rm -rf /etc/systemd/system/ccpd.service.d
rm -f  /etc/systemd/system/ccpd.service
rm -f  /etc/systemd/system/cups.socket.d/10-lan-631.conf
rm -f  /etc/udev/rules.d/5*-canon*.rules
rm -f  /usr/local/sbin/canon-usbreset /usr/local/sbin/canon-ipp9100.py
cp /etc/cups/cupsd.conf.bak.* /etc/cups/cupsd.conf      # 选最早的备份
systemctl daemon-reload
systemctl unmask ipp-usb && systemctl enable --now ipp-usb
systemctl restart cups avahi-daemon
```

驱动本身用 `dpkg -r cndrvcups-capt cndrvcups-common` 卸载。
